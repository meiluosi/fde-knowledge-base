**原因：这道题在第②层没过。** 按四层验收，找到文件、核验版本/状态与适用范围、取得正文并定位、解释适用条件，前面各层缺一，就不能说“已正确回答”。系统引用的是已废止的 2019 版，说明它没有核验出处的效力/状态。答案内容碰巧和现行版一致，只是“看起来对”，用户顺着这个出处去核对，看到的是一份已废止的文件。这类题恰恰是评测要抓的失败：对了的答案挂着错的依据，换一个新旧版本条款不同的问题，同样的机制就会给出错答案。

**建议这样标注：**

1. **层级逐层标**：①找到文件：看目标文件是否在候选里（如果系统连现行版都没找到，①也要如实标）；②核验版本/状态：未通过；③④：按“前面层未过就不算完成”处理，即使你觉得正文和解释没问题，也只作为越层标注记录，不计入完成。
2. **答案内容一致这件事照样记下来**：在备注里写“答案内容与标准答案一致，出处为废止的 2019 版”。这能帮你区分两种情况：现行版里这段话本来就没变（答案对是巧合，但出处错），还是系统其实读到了新内容却引了旧版标签。后者是出处标注问题，前者是版本治理问题，后续修的地方不同。
3. **用 `scripts/layer_report.py` 汇总**：它会把“后面层通过、前面层未过”单独列为越层标注，不算完成；完成率会按区间给，不会把这道题吃进分母。
4. **要求层级先看这道题是怎么定的**：如果业务验收要求只到①（只想知道有没有这份文件），那②不是这道题的验收线，可以另议；但只要题目是条款、金额、合规一类，要求层级通常至少到②③，这时挂废止版出处就不能算过。要求层级由业务负责人定，不由评测人员临时放宽。

**还有两点需要你确认，会改变处理方式：**

- 这道题的**标准出处**是否写的是现行版？如果标准出处本身就写成了 2019 版，那是评测集要先修：标准出处、版本和日期须由答案认可人（业务方）复核，不要自行改动。
- 2019 版是**被哪一版替代、替代关系谁确认过**？“已废止”这个判断要由客户的责任人（知识 Owner）作出；如果只是页面上有“废止”字样或你的印象，先找 Owner 确认状态，再据此标注。
